## Research question

How did positive trust ratings accumulate in the Bitcoin OTC network, and did already highly rated users attract a disproportionate share of new positive ratings?

The focused investigation is temporal network evolution. A supporting robustness analysis will test the role of highly rated nodes if it adds insight.

## Source and meaning

The source is the [SNAP Bitcoin OTC trust network](https://snap.stanford.edu/data/soc-sign-bitcoin-otc.html). Each row is `SOURCE,TARGET,RATING,TIME`: one user rated another from -10 to +10 at a recorded Unix time. These are ratings, not verified trades or fraud outcomes.

The original compressed source is `data/soc-sign-bitcoinotc.csv.gz`. Its SHA-256 is `6424ac981dad3a019f697fc1b9fcd85c19d8d9f039797758e9ffb6fea100c373`. Retain the original file and its download URL; derived tables must be generated by code. The source file is excluded from GitHub until redistribution terms are confirmed; `data/README.md` gives download instructions.
