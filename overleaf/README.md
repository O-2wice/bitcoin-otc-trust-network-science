# LaTeX report

[Download the Overleaf ZIP](bitcoin_otc_report_overleaf.zip).

The archive contains `main.tex`, the bibliography, Springer Nature template files, and all seven report figures.

1. In Overleaf, choose **New project → Existing project (.zip)** and select the archive.
2. Set the main document to **main.tex** and the compiler to **pdfLaTeX**.
3. Recompile, and check that the PDF has 10 to 15 pages. If it runs over, reduce the figure widths in `main.tex`.
4. Download the PDF and add it to the repository as `report/bitcoin_otc_report.pdf`.

[Overleaf upload instructions](https://docs.overleaf.com/managing-projects-and-files/uploading-a-project).
